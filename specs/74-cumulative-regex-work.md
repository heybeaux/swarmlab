## Required behavior and ownership boundary
Preserve synchronous public evaluate(call,compiledRules,opts) and existing loadPack. Bound cumulative native matching across all rules, targets and decoded variants in ONE evaluate call. Default total budget250ms; positive finite <=1000ms option regexTotalBudgetMs, rounded up, invalid values default250ms. Per-match option remains independent; remaining total caps each native run AND retries. Unknown is not nonmatch: unresolved rules require independent ask floor, even all-allow severity mapping. Distinct cumulative regex budget diagnostic once; no fabricated matches. Preserve already proven hits/order/dedup/first equal-severity reason, independently matched substring deny on either side of exhaustion, and predictor deny. Regex rules NOT reached after exhaustion are unresolved, not a fabricated deny. No executing regex after cumulative exhaustion; fresh budget per subsequent call, cache/statics/input slots cleared as before. No caller mutation/freezing. Skip disabled/inapplicable/absent targets; empty pack and native flags/lookbehind/backrefs compatibility. Aegis owns synchronous matching admission/uncertainty; host owns authentic policies, input provenance and execution. This is NOT an absolute evaluate/preprocessing/plan-building/compilation/loader/memory or arbitrary JS/proxy bound, trained prediction, malicious-host defense, or production certification.
