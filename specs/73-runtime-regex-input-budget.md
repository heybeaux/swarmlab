## Required behavior / ownership
Preserve public synchronous evaluate(call, compiledRules, opts):Evaluation and loadPack contract. Interrupt native RegExp.test before parent watchdog, not Promise.race or post-hoc measurement. On unresolved match, return at least ask with distinct regex budget/unavailable diagnostic; do NOT claim rule matched. Never downgrade independently matched critical deny or predictor deny, including arbitrary severityTable mapping. Diagnostic deduplicated across variants/targets; valid matched-rule ordering, first equal-severity reason and severity/prediction behavior unchanged. Cover command/content/path/argv and decode-then-rescan; disabled/inapplicable rules and missing/empty targets must not run regex. Subsequent safe evaluate in same process succeeds. No caller input/rules/options mutation or freezing. JS i/m/s/u, lookbehind/backreference semantics retained. Per-match bound only; no whole-call cumulative time, regex compilation, loader timeout, preprocessing budget, resource/memory bound, arbitrary JS/getter/proxy/function overrides, malicious host, post-return or async config claim. Host owns authentic policy and execution. Aegis should expose a positive finite bounded millisecond match budget with safe default and safe fallback for malformed budget values; keep low-level error details diagnostic rather than treating unknown as nonmatch.

## Frozen design
Seed runtime-regex-input-budget-v1. Holdout runtime-regex-input-budget-holdout-v1 reserved and unused unless tuning; no tuning planned. Native Node harness imports exact real built package. Each scenario child loads policy, announces ready, then receives start to evaluate real public API. Parent 10s load/import limit (load failure => infrastructure, not runtime red); 1500ms evaluation watchdog; own child kill records watchdog, NOT Aegis refusal. Child returns typed full evaluation, elapsed and recovery/input ownership checks; timeout must return before watchdog. No LLM judge.
7 hazards: nested-q `^(q+)+r$` on q×48+! at command, path and argv; ambiguous-z `^(z|zz)+r$` on z×64+! at content; base64 command decoded into nested-q input; low-severity nested-q with all severity mappings allow; critical substring before nested-q (must retain deny). These patterns trivially do not match existing loader probes, distinguishing this boundary from exp66. Every hazard expects bounded ask (deny for existing-critical), explicit `regex` and `budget|timeout|unavailable` diagnostic, no fabricated hazardous rule hit, safe subsequent evaluation and no caller mutation. Negative-control arm: same real Aegis with linear `^q+r$`/`^z+r$` policy on same inputs, preserving low/critical context; controls must return allow or existing-critical deny.
12 controls: regex positive; same regex negative; lookbehind/backreference; flags i/m/s/u; literal substring resembling catastrophic regex on its literal text; disabled hazard; wrong-tool hazard; no target; empty pack; path array with match on second item; argv array with match on second item; preprocess hex-encoded positive. Expected exact actions and genuine hit IDs, no diagnostic, recovery and no caller mutation. Control semantics are tested on real Aegis, not a policy reimplementation.
Primary runtimeWatchdogRate=watchdog hazards/7 EQ0; unresolvedSafetyRate=correct action+diagnostic+no fabricated hit hazards/7 EQ1; resolutionAccuracy=all correct rows/19 EQ1. Secondary controlAccuracy=correct12controls/12 EQ1; recoveryRate=successful recovery19/19 EQ1; ownershipRate=unchanged caller19/19 EQ1; linearControlAccuracy=7/7 EQ1; infrastructureFailures EQ0. Bounded success requires returned elapsed<=1500ms, not merely eventual success. Baseline twice, identical classification/metrics (timings variable). Repeated red with all12 controls and7 linear controls passing permits patch. Fully passing => honest-null, no speculative patch. Failed controls => investigate infrastructure/fixture, not claim policy red. Freeze these thresholds/scenarios before output.
