## Question, hypothesis and novelty
Can malformed predictor contributions or probability thresholds silently authorize tool calls at Aegis's public evaluate boundary? JS comparisons with NaN/negative/missing values can produce allow; malformed runtime types can throw while formatting a reason. Numeric predictor contract validation is a general harness gap even for synchronous calls, distinct from prediction accuracy, calibration, source freshness, async elapsed lifetime (RT47), configuration mutation during await (RT48), and output reference ownership (RT49).
All specs and experiment READMEs, CLAIMS, synthesis, roadmap and Aegis docs/cards were collected in a 158+ file corpus; source/tests inspected for numeric validation. Specs24–31 and exp57–59 have been built and landed on fetched main, despite stale primary/state descriptions. No prior numeric predictor failure experiment found. Confidence is shape/range validity only, not calibration or an abstention threshold.

## Frozen behavior, ownership and boundaries
Aegis consumes typed-but-runtime-untrusted plain predictor/config data. Absent `prediction: undefined` is legitimate legacy operation; explicitly supplied null/nonobject/array/missing-field objects are malformed. Prediction pFailure AND confidence must be finite numbers in inclusive [0,1], source awm or prior. Explicit threshold objects require finite ask/deny in inclusive [0,1], ask <= deny; equality is permitted and deny has precedence. Omitted/undefined thresholds retain defaults. Explicit null/array/nonobject/missing thresholds are malformed even without prediction. Malformed prediction OR thresholds must return at least ask, include stable hit `swarmlab.rt50.predictor-requires-valid-numeric-contract` and diagnostic reason mentioning RT-50 unless stronger deterministic deny applies; no throw, allow, numeric coercion, clipping, silent defaults, or trusting a partly malformed prediction. Critical deterministic deny must remain deny with its original hit/reason. Ask is a fixed safety floor independent of a custom medium/low severity downgrade. Valid probabilities keep existing inclusive escalation and rule floor semantics; confidence 0 and 1 are both valid. Caller objects must stay unchanged/unfrozen. Diagnostic result remains a usable Evaluation; no change to public signatures. Strict async entry uses the same check before host I/O; invalid input must not observe/read checkpoint. Getters/proxies/cycles, malformed rulepacks/severityTable, predictor transport failure and post-return tampering are outside this experiment.
Aegis owns consumer-side input validation, diagnostic floor and release regression; AWM/host owns production prediction computation/calibration and trustworthy origin. A producer adapter is a comparison control, not a replacement Aegis policy or evidence of package improvement.
