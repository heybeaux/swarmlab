## Unique hypothesis / dedup
`loadPack` validates stateless i,m,s,u flags and compiles a regex, but public CompiledRule is mutable and evaluate trusts its cache indefinitely. A valid loaded rule whose declared pattern/flags or cached RegExp changes BETWEEN completed evaluations can silently authorize a call against a stale/unrelated/stateful matcher. Missing regex can silently disable an enabled guard. Expected shortfall: no explicit refusal when compiled source/flags diverge from RuleMatch, or unsupported g/y cache introduces state. This tests configuration validity AT invocation, not RT48 mutation DURING awaited I/O (exp58 explicitly excludes lastIndex and presumes valid config). RT49 isolates receipt references AFTER return, RT50 validates Prediction, RT51 isolates ambient default templates; none bind compiled matcher to declared rule.
