## Ownership / required behaviors
Preserve public synchronous loadPack(pack):CompiledRule[], RulePackError and packId/ruleId; reject entire pack, never return partial compiled policy. Fail closed on exceeded/unavailable deadline, without executing arbitrary pattern as script. Preserve exact JS regex flags/features, substring bypass, ordering, duplicate/shape/syntax/flag errors, editable independently owned outputs and inputs. Timeout must interrupt native regex, not Promise.race or an elapsed check after blocking. A timed-out probe must not poison subsequent valid loads in same process. Environment budget is a positive finite millisecond number, rounded up to an integer; absent/invalid/nonpositive/out-of-range uses default25ms rather than disabling the guard or throwing unrelated RangeError. Host owns authentic policies and real tool execution. Finite probe corpus is NOT a proof of general regex safety or bounded runtime evaluation; no changed evaluation API, no full pack cumulative budget, no arbitrary getter/proxy/cycle/hostile JS code claim.

## Frozen design / controls / machine oracle
Seed `loader-probe-preemption-v1`, reserved holdout `loader-probe-preemption-holdout-v1` unused unless tuning (no tuning planned). No LLM judge/random sampling. 19 fixed scenarios in `scenarios.mjs`:
- 5 hazards: nested-a `^(a+)+b$`; ambiguous-a `^(a|aa)+b$`; nested-slash `^(/+)+x$`; mixed safe prefix then nested-a; disabled nested-a. Each must return RulePackError with exact pack/rule binding and ReDoS/budget diagnostic BEFORE parent watchdog, never load any rules; then a safe subsequent load must work in that child.
- 14 controls: linear regex; lookbehind+backreference; i/m/s/u flags; substring literal resembling nested regex; empty pack; invalid g flag; duplicate id; invalid syntax; missing appliesTo; env budgets `0`, `NaN`, `Infinity`, `-1`, `1.5` on safe regex. Valid controls must load synchronously, preserve original RegExp source/flags, repeated matching semantics and source recipe, and allow later safe load. Error controls must preserve RulePackError classification and exact binding.
Arms: real public built Aegis loadPack; substring negative control using identical hazardous text as a substring (real Aegis, no substitute policy). The 5 substring negative-control runs must load normally.
Each fresh child imports real built package then announces ready (10s import limit). Parent sends start and starts fixed1500ms watchdog, kills only its own child on expiry, records watchdog red (not a library rejection). Deadline threshold intentionally broad vs25ms, not a microbenchmark. Import/IPC/crash/unexpected output is infrastructure-blocked, NOT policy red. All finite inputs fixed; whole experiment bounded to <2min. Execute baseline twice; classification/checks/metrics must repeat (raw elapsed diagnostic expected variable). Preserve stderr/stdout, child result, ready/start/end, exit/signal, full artifact manifest, exact SHA/dirty and harness/scenario hash. Ground truth is typed outcomes, binding and explicit checks, never exit0 alone.

## Immutable thresholds
